# 📒 دفتري - نظام الأقساط الفاخر

> نظام إدارة أقساط فاخر - تصميم أسود وذهبي - يشتغل على كل الأنظمة

## ✨ المميزات

- 📱 يشتغل على كل الأجهزة - Android, iPhone, Mac, Windows, Linux
- 🎨 تصميم فاخر - أسود وذهبي ملكي
- 👥 إدارة الزبائن - إضافة، بحث، تسديد أقساط
- 💾 حفظ تلقائي - بياناتك ما تضيع + نسخ احتياطي يومي
- 📲 PWA - تقدر تثبته كتطبيق على الموبايل
- 🔒 آمن - كل زبون عنده رقم صاحب المحل

## 🚀 التشغيل السريع

### على الكمبيوتر:
pip install -r requirements.txt
python run.py

### على الموبايل (نفس الشبكة):
http://IP_الكمبيوتر:8000
